# Screen Recorder (Instant Replay)

Програма на C++ для фонового запису екрана. Тримає останні кілька секунд відео в кільцевому буфері в оперативній пам'яті та зберігає їх у `.mp4` за натисканням гарячої клавіші або кнопки в інтерфейсі.

- **Документація (Doxygen):** https://ent72.github.io/Recorder/
- **Звіт-ретроспектива (Лабораторна робота №3):** [RETROSPECTIVE.md](RETROSPECTIVE.md)

## Використані бібліотеки

- **OpenCV (`core`, `imgproc`, `videoio`)** — відповідає за роботу з кадрами та рендер відео. Захоплені кадри зберігаються як `cv::Mat` (під час збереження кліпу робиться `clone()`, щоб не блокувати потік запису). Оскільки WinAPI віддає картинку в BGRA, перед записом у файл вона конвертується в BGR через `cv::cvtColor`. Саме відео збирається через `cv::VideoWriter` (кодек `mp4v`) з урахуванням реального FPS.
- **WinAPI (`windows.h`)** — використовується для захоплення екрана та роботи з гарячими клавішами. Скріншоти знімаються через стандартні функції GDI (`GetDC`, `CreateCompatibleDC`, `BitBlt`, `GetDIBits`), а натискання клавіші відстежується у фоні через `GetAsyncKeyState`.
- **Qt 6 (`QtWidgets`)** — графічний інтерфейс: головне вікно, налаштування (FPS, тривалість буфера, вибір клавіші) та перегляд збережених кліпів.
